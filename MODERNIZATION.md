# Modernization roadmap

Original repository: https://github.com/kunzaZa183/Database

This repository contains a clean source snapshot rather than a copy of historical Git commits. The original repository preserves the historical versions.

## Milestones
1. Baseline testing of database creation and loading with synthetic data.
2. Consistent navigation, typography and Qt stylesheet.
3. Separate UI, data access and business rules while preserving schema.
4. Improve search, validation and reporting.
5. Test and package the desktop app.

## Safety
Do not commit real sponsorship records, SQLite database files, credentials, or personally identifiable test data.
